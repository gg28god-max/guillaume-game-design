Outpost Red — UI/UX & Concept Art Case Study

02 — Art Brief

The Brief

Outpost Red asked for two things at once: concept art grim enough to sell a contamination event, and a UI system polished enough to actually run in an engine. The brief below is what I held both halves of the project to.

Premise

A concept art and UI/UX case study set in the aftermath of an extraterrestrial contamination event on a long-range Martian expedition — sterile aerospace technology set against visceral, bioluminescent infection, carried across a mechanical rover, a ruptured space suit, and the crew themselves.

Mood & Tone

Hard-sci-fi survival horror — a desaturated Martian palette broken only by a hazard-orange UI accent, so the technology reads as clinical and the infection reads as wrong. Isolation first, monster second.

Deliverables

Full concept art (rover and contaminated-crew character design) alongside a complete production UI pipeline — information architecture, user flow, wireframes, style guide, and high-fidelity screens — built as real, functioning UMG widgets in Unreal Engine 5, not stopped at the mockup stage.

Pipeline & Constraints

Figma for design and specification, Unreal Engine 5 and UMG for implementation. Every screen had to survive the jump from a flat Figma frame to a data-driven, event-connected system — skill trees, crafting matrices, in-game shops, and inventory all had to actually work, not just look finished.

03 — The Problem

The Problem I Set Out to Solve

Making body horror read as still human

The contaminated crew member had to be horrifying without stopping being a person in a suit. The bioluminescent growth needed to overtake the body without erasing the silhouette underneath — the helmet, the harness, the boots all stay legible, because the horror is in what's still recognizably human, not in what isn't.

A UI that survives the jump from Figma to a live engine

Most UI case studies stop at a polished mockup. I set the constraint of building the whole system as functioning UMG widgets — skill tree, crafting, shop, inventory, HUD — inside Unreal Engine 5, so every visual decision also had to be a technical one: what's data-bound, what fires an event, what has to update in real time.

One visual language across two disciplines

The same aerospace-meets-infection tone had to hold whether I was painting a rover or laying out a data-bound inventory grid, so the interface reads as part of the same fiction as the concept art — not a system bolted on top of it.
