Sports · VR Design · Meta Quest · 2023

Home Run Derby VR

Developed in partnership with MLB for the All-Star Game Championship, Home Run Derby VR is a premium Meta Quest sports simulation. Serving as Lead Architect for the game's UI Visual Identity, the project required engineering a clean, high-performance design system — from typography and color palettes through button components, tournament UIs, first-time user experience flows, progression systems, and Season 3 interface updates.

Year

2023

Role

Lead UI Architect

Client

MLB / Little Guy Games

Platform

Disciplines

03 — Art Brief

The Brief

Home Run Derby VR needed a UI that could carry a licensed MLB property into a headset without losing what makes it feel official, while still working as a genuinely usable VR interface. The brief below is what I held the whole system to.

Premise

A licensed MLB VR title for Meta Quest and SteamVR, developed at Little Guy Games in partnership with Major League Baseball for the All-Star Game Championship — arcade home run gameplay wrapped in a full live-service structure of prestige progression and seasonal tournaments.

Mood & Tone

Broadcast-sports energy — bold blues, gold, and red pulled straight from MLB's own brand system, built to read as a premium licensed product rather than an indie VR experiment.

Deliverables

As Lead UI Architect: typography and color system, button components, first-time user experience (controller onboarding and stance selection), the full tournament creation, lobby, and bracket flow, profile progression, and a Season 3 interface update to keep the system alive past launch.

Pipeline & Constraints

Figma for the design system, Photoshop for vector-based icons and text effects, every screen tested in-headset for readability and scale. Nothing could ship as a flat overlay — the whole system had to work as a floating 2D/3D spatial UI viewed at arm's length.

04 — The Problem

The Problem I Set Out to Solve

Designing for a controller, not a cursor

The first-time user flow has to teach a totally unfamiliar input method — point a laser at a graphic, pull a trigger — before the player has even swung a bat. The stance-selection screens show three distinct states (default, laser hovering, selected) because in VR, if the player doesn't know what's clickable, they're stuck before the game even starts.

A UI that still reads as MLB at arm's length

This is a licensed property, so brand fidelity to MLB's visual identity wasn't optional — but flat brand assets don't automatically hold up at VR viewing distance. Every typeface size and color choice was tested in-headset rather than on a monitor, so the interface would stay legible without diluting the license it was built to represent.

Building for a season, not a launch

Live player stats, ready-checks, and multi-round brackets meant the tournament UI had to handle real-time state, not just display static art. And a Season 3 interface update after launch meant the original design system had to be built extensible from day one, not patched together after the fact.
