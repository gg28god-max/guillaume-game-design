01 — PROJECT INFO

Home Run Derby VR

A licensed MLB VR title combining arcade home run action with immersive professional ballpark environments.

Home Run Derby VR is a licensed Major League Baseball title for Meta Quest and SteamVR, blending arcade home run gameplay with deep prestige progression systems and competitive seasonal tournaments. Developed at Little Guy Games, the project required fully immersive ballpark environments built for standalone VR performance — from stadium architecture and crowd seating to hand-crafted props and VR-optimized equipment assets. The pipeline focused on high-fidelity graphics optimized for VR’s unique rendering constraints, including a floating 2D/3D spatial UI tested in-headset for readability and scale.

04 — DESIGN SYSTEM & STYLE GUIDE

One System, Every State Documented

Agency FB condensed sports typography, official MLB color tokens, and full interactive states (Default, Hover, Click) engineered for VR laser pointers.

3 SPECIFICATION SHEETS

Typeface

Agency FB in Black Italic Bold Cap, Regular Cap, and Italic weights — one condensed sports-broadcast face carrying headers, body, and telemetry alike.

Color

Black backgrounds, white strokes, and a blue/green/red button family — the same three hues double as status tokens for error, success, and loading fields.

Components

Buttons, toggles, checkboxes, fields, and notifications — every component specified in Default, Hover, and Click so engineers never have to guess.

07 — HEURISTICS & VALIDATION

Reviewed In-Headset, Not On a Monitor

Shipped as a live, MLB-partnered title for Meta Quest. Validation was conducted via continuous heuristic audits against VR constraints across every iteration cycle.

Can you find it without hovering?

Every interactive element checked for an explicit hover state that reads at laser-pointer distance, not just up close on a 2D monitor.

Can you hit it with a shaking hand?

Target sizes and spacing calibrated against natural hand-tracking jitter, especially during initial stance selection and match confirmation.

Does it still read as MLB at distance?

Official brand typography and contrast curves inspected in stereoscopic 3D space to prevent sub-pixel shimmering and edge aliasing.

08 — OUTCOME

What Shipped, and What Held Up

Shipped for the All-Star Game

The full UI system launched as a licensed MLB product for the All-Star Game Championship on Meta Quest — fully brand-approved and certified for production.

Extensible Past Launch

The Season 3 interface update reused the original design tokens and component architecture without rebuilding — proving the system was architected to extend.

A Reusable VR UI Language

Default, hover, and selected states, target geometries, and distance-tested typography became a lasting studio design standard for 6DoF titles.

09 — REFLECTION

What VR Taught Me About Flat UI

Designing without a cursor forces a kind of honesty that flat-screen UI can hide from: if a state isn't obvious without hovering, it isn't obvious. That constraint didn't just shape Home Run Derby VR — it's changed how I evaluate every interface I design since, VR or not.
